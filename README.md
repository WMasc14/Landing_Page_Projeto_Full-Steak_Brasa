# 🥩 Full-Steak Brasa — Landing Page

Uma Landing Page moderna, responsiva e focada em conversão para a **Full-Steak Brasa**, uma steakhouse e hamburgueria especializada em cortes e hambúrgueres artesanais preparados na brasa.

---

## 🚀 Sobre o Projeto

Este projeto foi desenvolvido como parte prática de estudos da **BGTech Academy** (Formação Full-Stack com IA). O objetivo principal foi criar uma página institucional de alto impacto visual que conectasse o cliente final diretamente aos canais de atendimento e ao cardápio do estabelecimento.

### 🌟 Principais Funcionalidades

* **Navegação Fluida (Smooth Scroll):** Âncoras que levam o usuário direto para as sessões de Experiência, Diferenciais e Mais Pedidos.
* **Vitrine de Produtos:** Exibição dos pratos mais pedidos com preços, imagens descritivas e badges promocionais.
* **Foco em Conversão (CTA):** Botões estratégicos de "Pedir pelo WhatsApp" espalhados pela página, além de um **botão flutuante fixo** para atendimento rápido.
* **Design Responsivo:** Adaptado para leitura ideal tanto em dispositivos móveis quanto em computadores.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais, priorizando a semântica e a performance:

* **HTML5:** Estruturação semântica de toda a página (tags como `<header>`, `<section>`, `<article>`, `<footer>`).
* **CSS3:** Estilização e layout (via arquivo `style.css` externo).
* **Boxicons:** Biblioteca de ícones vetoriais usada para as redes sociais e o símbolo do WhatsApp.
